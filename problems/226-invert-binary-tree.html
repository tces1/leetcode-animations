226. 翻转二叉树 · 先交换再递归

对每个非空节点执行 Swap → Left → Right：先交换左右子树引用，再递归处理交换后的新左子树与新右子树。
递归主线
① BASE
root is None 时直接返回，不创建或删除节点。
② SWAP
root.left, root.right = root.right, root.left，交换两条子树引用。
③ DESCEND
先递归新的 root.left，再递归新的 root.right。
④ RETURN
左右子树都已镜像后，返回同一个 root 节点。
交换的是子树引用，不是节点值。节点的 id 与 value 始终不变；改变的是每个节点的 left/right 指向。每个实际节点恰好访问并交换一次。
示例： 经典完全树 非完全 [2,1,3] 单节点 空树 左斜树 含负数
接受空白分隔（1 null 2）或逗号分隔（[1,null,2]），可带一对方括号；null 与 # 表示空位置，且必须小写。 空输入、[]、单独的 null 或 # 表示空树。支持负数与重复值；节点值须为 −1,000,000～1,000,000 的整数。严格拒绝空 token、混合分隔、未配对括号、根为空后仍有 token，以及没有可用父节点的孤儿 token。

复杂度
时间 O(n)每个实际节点恰好访问一次，并进行一次常数时间的左右引用交换。
递归栈 O(h)h 是树高；平衡树为 O(log n)，额外的页面快照不属于算法本身的空间开销。
最坏 O(n)左斜树或右斜树的高度等于节点数，递归调用栈会增长到 n 层。

101. 对称二叉树 · 直接镜像递归

不翻转、不复制、不修改原树；直接让两个指针同步走向镜像位置，判断结构和值是否完全对应。
compare(left, right) 的四条规则
① BOTH NULL
两个指针都为空，当前镜像子问题返回 True。
② ONE NULL / VALUE
只有一个为空，或两个值不同，立即返回 False。
③ OUTSIDE
先比较外侧：compare(left.left, right.right)。
④ INSIDE
外侧为 True 才比较内侧：compare(left.right, right.left)。
镜像不是“左右子树值集合相同”。结构位置也必须镜像；Python 的 and 从左到右短路，外侧失败后不会进入内侧子问题。
示例：对称结构不对称值不对称重复值对称单节点空树
接受空白分隔或逗号分隔，可带一对方括号；null / # 必须小写。空输入、[]、单独的 null 或 # 表示空树。支持负数、重复值和不完整树；严格拒绝空 token、混合分隔、未配对括号、空根后的额外 token 与孤儿 token。

46. 全排列 · 回溯动画

用 path 保存当前排列，用 used[i] 标记 nums[i] 是否已经选过。每层扫描所有候选：已使用就跳过，否则执行选择 → 递归 → 撤销。
回溯流程
① 状态
path 是当前路径，used 防止同一元素重复出现。
② 扫描
每层从下标 0 开始扫描；遇到 used[i] 就跳过。
③ 选择 / 递归
加入 nums[i]，置 used[i]=true，递归下一层。
④ 收集 / 撤销
len(path)==n 时收集；返回后 pop 并恢复 used。
必须保存副本：result.append(path[:])。path 会持续被 pop 和复用；若直接保存它，所有结果都会引用同一个可变列表。
示例： [1,2,3][4,9][-7][-2,5,11]
请输入 1～7 个互不相同的安全整数，格式如 [1,2,3]；n=7 会产生较多动画帧。
候选数组 nums / used 状态
当前递归路径 path
调用栈（底 → 顶）
已经收集的排列（按 DFS 顺序）

438. 找到字符串中所有字母异位词 · 滑动窗口动画

异位词只关心每个字母出现多少次，不关心顺序。因为答案窗口的长度一定等于 len(p)，所以用一个固定长度窗口从左向右滑动：右边进入一个字符，左边离开一个字符，每次只更新两个计数。
固定窗口四步
① 统计目标
cnt_p = Counter(p)，一次得到模式串每种字母的出现次数。
② 右端进入
遍历 s，执行 cnt_s[c] += 1，让当前字符进入窗口。
③ 窗口成形
计算 left = right-len(p)+1；left 小于 0 时窗口长度还不够。
④ 比较后移出
窗口成形后比较 cnt_s == cnt_p；随后左端字符计数减 1，为下一轮滑动做准备。
核心判断：窗口长度固定为 len(p)，所以只要两个 Counter 完全相等，当前窗口就是异位词。字符集只有 26 个小写字母，Counter 比较的开销是常数级字符集扫描，整体仍为 O(n)。
方法二 · 单 Counter + 超量收缩：字符进入时令 cnt[c] -= 1；若新字符 c 变成负数，说明 c 超量，就移动 left 直到 cnt[c] == 0。此时窗口内每种字符都不超过 p；若窗口长度又恰好等于 len(p)，总字符数相同便能推出所有频次完全相等。
示例： 经典 [0,6] 重叠窗口 [0,1,2] 重复字母 [1] p 更长 [] 连续匹配 没有答案
仅支持小写英文字母；s 长度 1～24，p 长度 1～10。

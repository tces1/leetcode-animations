98. 验证二叉搜索树 · 上下界递归

每个节点必须落在从所有祖先继承的开区间 (lower, upper) 中；左移收紧上界，右移收紧下界。
为什么必须携带祖先上下界
① BASE
node is None 返回 True；空子树天然满足 BST。
② CHECK
严格检查 lower < node.val < upper，等于任一边界也失败。
③ LEFT
左子树继承 lower，并把 upper 收紧为 node.val。
④ RIGHT
右子树继承 upper，并把 lower 收紧为 node.val。
BST 不允许重复值。因此必须使用严格 <，不能使用 <=；重复值会恰好撞上祖先或父节点边界。
只比较父子节点不够：[5,4,6,null,null,3,7] 中，3 虽然小于父节点 6，却位于根 5 的右子树，必须满足 3 > 5。它继承区间 (5, 6)，因违反祖先下界 5 而失败。
示例： 合法 [2,1,3] 经典直接违规 祖先隐藏违规 重复值 单节点 空树
接受空白分隔（1 null 2）或逗号分隔（[1,null,2]），可带一对方括号；null 与 # 表示空位置，且必须小写。 空输入、[]、单独的 null 或 # 表示空树。支持负数、重复值和不完整树；节点值须为 32 位有符号整数。严格拒绝非法或空 token、混合分隔、未配对括号、根为空后仍有 token，以及没有可用父节点的孤儿 token。

递归栈 O(h)额外空间等于树高 h；平衡树为 O(log n)，斜树最坏为 O(n)。

73. 矩阵置零 · 原地标记动画

若某个元素为 0，就把它所在的整行和整列都置为 0。为了做到额外空间 O(1)，借用第一列记录哪些行要清零、借用第一行记录哪些列要清零；再让左上角 matrix[0][0] 兼任第一列的整体标记，只额外保存一个布尔变量。
原地标记四步
① 只保存第一行
用 firstRowZero = 0 in matrix[0] 记住第一行原本是否含 0；第一列交给 matrix[0][0] 标记。
② 连同第一列一起扫描
从第 1 行开始，列从 0 开始。遇到 0 就令 matrix[r][0] = matrix[0][c] = 0。
③ 每行从右往左清零
根据行首或列首标记置零；必须让 c 倒序，使该行的 matrix[r][0] 最后才被修改。
④ 最后处理第一行
其它行（包括第一列）都已完成后，只根据 firstRowZero 决定是否清零第一行。
为什么第二遍必须倒序？matrix[0][0] 为 0 表示第一列要清零。若正序先改 matrix[r][0]，它会立刻变成 0，随后该行其它格子会误以为“整行需要清零”。从右往左处理，先用完行标记，最后才安全地修改第 0 列。
示例： 中心为 0 首行含 0 首列与内部含 0 没有 0 单元素 0
行用分号隔开，元素用空格或逗号隔开；支持 1～6 行、1～7 列的整数矩阵。

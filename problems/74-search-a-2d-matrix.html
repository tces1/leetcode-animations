74. 搜索二维矩阵 · 展平二分动画

每行从左到右有序，且下一行开头大于上一行末尾，所以整张表其实是一条有序数组。把下标 i 映射成 (i // n, i % n)，一次二分即可，时间 O(log(mn))。
思路要点
① 全局有序
本题比 240 更强：行与行之间也衔接有序，可以当成长度为 m·n 的一维数组。
② 下标映射
mid → 行 mid // n、列 mid % n。不必真的拷贝成一维数组。
③ 标准二分
当前值偏小就丢掉左半 left = mid + 1；偏大丢掉右半 right = mid - 1。
④ 找到即返
相等直接 return true；区间空了就是 false。空间 O(1)。
和 240 的区别：240 只保证「行升序、列升序」，不能展平后二分，要从右上角阶梯走。74 多了「下一行开头 > 上一行末尾」，所以整表单调，一次二分就够。
示例： 找 3（存在） 找 13（不存在） 找 60（末尾） 单行找 4 单列找 6
需满足每行升序，且下一行开头大于上一行末尾；行列各 ≤ 6（动画清晰度上限）。
二维矩阵（角标 = 展平下标）
mid → (mid // n, mid % n)
一维视角 · left / mid / right

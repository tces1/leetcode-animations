79. 单词搜索 · 回溯动画

在棋盘上四向走，走出 word。用下标 start 表示已经匹配到第几位；当前格改成 # 防止走回头，四个方向都失败后再改回来。最后一位匹配成功就返回 True。
回溯流程
① 起点
枚举每个 board[i][j] == word[0] 的格子，调用 goin(i, j, 0)。
② 终止
start == len(word)-1 说明当前格已经是单词最后一位，成功。
③ 标记
把当前格改成 #，再看上下左右是否等于 word[start+1]。
④ 撤销
四个方向都走不通，把 # 改回原字母，换下一条路或下一个起点。
用下标，不要切片：word[1:] 每层都复制字符串。传 start+1 是 O(1)。# 比把坐标放进 list 再 in 查找便宜得多。
示例： ABCCED → true SEE → true ABCB → false ACDB → true
棋盘 1～4 行、1～6 列，格子为单个字母；单词长度 1～8。可直接贴力扣的二维数组格式。
棋盘 board（紫=路径，黄=正在看的邻居，黑=# 已占用）
单词 word（绿=已匹配，紫=当前格，黄=下一个要找的字母）
调用栈（底 → 顶）

208. 实现 Trie（前缀树）· 动画演示

TrieNode 专门保存节点的 children 映射与 isEnd 标记，Trie 负责管理根节点和三种操作。相同前缀会沿用同一批节点；一条路径存在并不代表它已经是完整单词。
三种操作
① insert
逐字符沿 children 走；边不存在就新建节点；最后令 isEnd=true。
② search
路径必须完整存在，并且末尾节点必须满足 isEnd=true。
③ startsWith
只要求整条前缀路径存在，不检查末尾的 isEnd。
④ 共享前缀
插入 apple 后再插入 app，前三个字符节点会复用，只新增完整单词标记。
⑤ 职责分离
TrieNode 表示树节点；Trie.root 是空字符根节点，公开方法只负责从根开始移动。
设参数长度为 L：每次 insert / search / startsWith 的时间都是 O(L)。查询不增加空间；一次插入最多新增 L 个节点，但 Trie 的总空间由所有插入操作实际创建的字符节点数决定。
示例： insert:apple;search:apple;search:app;startsWith:app;insert:app;search:app;insert:apple insert:car;insert:cat;insert:care;search:cap;startsWith:ca;search:car insert:a;insert:ab;search:a;search:abc;startsWith:abc
格式：op:word，以分号分隔。仅接受小写 a-z；1～16 个操作，每个单词 1～12 个字符，总字符数不超过 120。

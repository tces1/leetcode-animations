76. 最小覆盖子串 · 可变滑动窗口动画

右端不断扩张，直到窗口覆盖 t 的全部字符；窗口一旦合法，左端就持续收缩并更新最短答案，直到移走一个关键字符使窗口失效。只维护一个 Counter 作为“剩余需求”，再用 cnt 记录尚未满足的字符种类数。
单 Counter 滑动窗口四步
① 剩余需求
need = Counter(t)；正数表示还缺，0 表示刚好，负数表示窗口里有多余字符。
② 右端扩张
目标字符进入时执行 need[c] -= 1；若结果第一次变为 0，说明该字符种类满足，cnt -= 1。
③ 持续收缩
只要 cnt == 0，窗口就合法：先记录更短答案，再移走左端字符。
④ 窗口失效
目标字符离开时执行 need[c] += 1；若结果大于 0，窗口重新缺少它，cnt += 1。
核心不变量：need[c] = t 中 c 的数量 − 当前窗口中 c 的数量。cnt 等于 need 中正数键的数量，所以 cnt == 0 就表示所有字符都已覆盖；重复字符也会自然处理。
示例： 经典 BANC 重复字符 aa 无解 重复需求 baa 较长 cwae 区分大小写
支持英文字母并区分大小写；s 长度 1～24，t 长度 1～10。

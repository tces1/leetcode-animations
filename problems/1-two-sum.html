1. 两数之和 · 哈希表动画

扫描到 x = nums[i] 时，先计算 complement = target - x，再去哈希表查找补数。若找到就返回两个下标；否则才记录 x → i。平均时间 O(n)，额外空间 O(n)。
一次扫描四步
① 读取当前值
从左到右扫描，令 x = nums[i]。
② 计算补数
由 x + complement = target 得到 complement = target - x。
③ 查询哈希表
哈希表保存的是此前元素的值 → 下标，平均 O(1) 判断补数是否出现。
④ 未命中才写入
找不到补数时记录 seen[x] = i，留给后面的元素匹配。
顺序不能反：必须先查后存。例如 nums=[3,3], target=6，扫描第一个 3 时哈希表还是空的，不会错误地让同一个下标同时充当两个元素；扫描第二个 3 才会匹配下标 0。
示例： 经典 [0,1] 答案 [1,2] 先查后存 含负数 较晚命中 无解演示
支持 2～16 个整数；数组元素限 -1,000,000～1,000,000，target 限 -2,000,000～2,000,000。

230. 二叉搜索树中第 K 小的元素 · 中序排名

BST 的中序遍历 Left → Root → Right 天然得到严格升序序列；第 k 个被访问的节点就是答案。
示例： 经典 k=1 经典 k=3 k=节点数 单节点 负值 BST
树接受空白分隔（3 1 4 null 2）或逗号分隔（[3,1,4,null,2]），可带一对方括号；null 与 # 必须小写。 节点值须为 32 位有符号整数。严格拒绝非法/空 token、混合分隔、未配对括号、根为空后仍有 token、孤儿 token，以及违反祖先严格上下界或含重复值的非 BST。还要求 1 ≤ k ≤ 节点数。

22. 括号生成 · 回溯动画

left / right 是还没放出去的 ( 和 ) 数量。已平衡时（left >= right）只能再放左括号；还有未匹配的左括号时（left < right），左右都可以放。两边都放到 0 就收集。
回溯流程
① 状态
res 是当前字符串，left/right 是剩余括号数。
② 已平衡
left >= right 时序列里左右括号一样多，只能放 (。
③ 未闭合
left < right 时可以放 (（若还有）或 )。
④ 收集 / 撤销
都为 0 时收集；返回后 res = res[:-1]。
不会出现非法串：右括号只会在 left < right 时放入，也就是已经用掉的 ( 比 ) 多。Python 字符串不可变，resp.append(res) 不必再 copy。
示例： 1234
请输入 1～4 的正整数。方案数是卡特兰数：n=3 有 5 种，n=4 有 14 种。

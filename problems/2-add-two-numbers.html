2. 两数相加 · 逐位进位动画

两个链表都按个位到高位的逆序保存数字。每轮读取当前数位，计算 x + y + carry，用 dummy / tail 新建并串起结果节点。
每个数位固定三步
① 读取当前位
指针为空时该数位按 0 计算，因此两条链长度可以不同。
② 求数字与进位
sum = x + y + carry，digit = sum % 10，carry = sum // 10。
③ 新建结果节点
tail.next = ListNode(digit)，移动 tail 与仍存在的输入指针。
循环不能只看两个指针：条件必须是 while p1 or p2 or carry。这样最高位产生的最终进位会额外生成一个结果节点。时间 O(max(m,n))；除结果链表外额外空间 O(1)。
示例： 342 + 465 最终进位 长度不同 0 + 0 单节点进位
每条链必须含 1～10 个节点，每个节点只能是 0～9 的一位数字；只接受空格或单个逗号分隔。

236. 二叉树的最近公共祖先 · 分治后序回传

每个递归调用只向父节点报告一个“信号”；父节点等待左右信号后执行合并。
递归返回值不是始终表示 LCA：它是三种多态信号
None当前子树没有找到 p 或 q。
p 或 q当前子树只报告找到了一个目标；它不一定已经是公共祖先。
其他节点当前子树已经合并出 LCA；祖先会通过 left or right 将它原样上传。
if left and right: return root 是分治合并条件，不是边界条件。
None + None → NoneX + None → XNone + X → XX + Y → 当前 root
当 p 是 q 的祖先：递归命中 p 就立即返回 p，不再搜索 p 的子树。因为题目保证 q 确实存在，最外层最终返回 p，p 即 LCA；这正是标准算法的目标短路。
示例： 经典分居 → 3 同侧祖先 → 5 更深同侧 → 5 根为目标 → 3 两叶子 → 5
树值必须唯一且为 32 位有符号整数；p、q 必须都存在并且不同。接受逗号或空白分隔，可带一对方括号；null / # 必须小写。严格拒绝空树、空/非法 token、混合分隔、孤儿 token、重复值和不存在的目标。

时间 O(n)最坏访问每个节点一次；若较高位置命中 p 或 q，会立即返回并跳过其整棵子树，实际访问可少于 n。
递归栈 O(h)h 为树高；平衡树 O(log n)，斜树最坏 O(n)。动画快照仅用于演示，不计入算法空间。

4. 寻找两个正序数组的中位数 · 切组划分

不合并数组。在两个有序数组上各切一刀，让左组刚好 ts = (m+n)//2 个，且左组都能 ≤ 右组。只在较短数组上二分刀口 m_idx，另一刀 n_idx 用公式算出来。时间 O(log(min(m,n)))。
切组要点
① 左组个数
左半固定拿 ts = s//2 个。奇数中位数是右组最小；偶数是 (左最大 + 右最小) / 2。
② 刀口下标
m_idx 是 nums1 左组最后一个下标，可以为 -1（一个都不拿）。n_idx = ts - (m_idx+1) - 1。
③ 合法切
交叉比较：m_l <= n_r 且 n_l <= m_r。越界用 ±∞ 当哨兵。
④ 怎么挪刀
n_l > m_r → nums1 多拿，l = m_idx+1；否则 nums1 少拿，r = m_idx-1。
二分区间：l = max(-1, ts-n-1)，r = min(m-1, ts-1)。既允许空左半，又保证 n_idx 落在 [-1, n-1]。nums1 更长时先交换，保证在短数组上二分。
示例： 奇数 · 需交换 偶数经典 nums1 取 0 个 一侧为空 全相等 重复交错
每边最多 8 个整数，至少一个非空；必须非递减。动画按交换后的短数组叫 nums1。

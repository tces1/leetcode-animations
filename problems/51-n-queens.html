51. N 皇后 · 回溯动画

在 n × n 棋盘上放置 n 个皇后，使任意两个皇后都不能同行、同列或同斜线。最自然的搜索方式是一行放一个：当前行逐列尝试，冲突就剪枝；安全就递归到下一行；后面走不通时撤销皇后，继续尝试下一列。
回溯四步
① 状态
row 表示当前要放的行；前面每一行已经恰好放了一个皇后，所以天然不会同行。
② 选择与剪枝
枚举当前行的每一列。若列或任一对角线已经被占用，立即跳过。
③ 递归
安全时记录列和两条对角线，把皇后放下，然后递归处理 row + 1。
④ 撤销
递归返回后移走皇后，并从三个集合里删除对应标记，继续试下一列。
对角线不必画线判断：同一条 ↘ 主对角线上的格子都有相同的 row - col；同一条 ↙ 副对角线都有相同的 row + col。因此三个集合 cols、diagDown、diagUp 就能在 O(1) 时间判断冲突。
示例： n=1（唯一解） n=4（2 个解） n=5（10 个解） n=6（4 个解） n=8（92 个解）
支持 n=1～8。n 越大搜索步骤越多；学习回溯建议先看 n=4。

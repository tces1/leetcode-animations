51. N 皇后 · 回溯动画

在 n × n 棋盘上放置 n 个皇后，使任意两个皇后都不能同行、同列或同斜线。queen(r) 表示给第 r 行找列；已放的皇后记在 res 里。进入每一行时，把已放皇后的攻击投影到当前行，得到禁止列集合 ban_c，然后 for c in range(n)，只有 c not in ban_c 才放下并递归。
回溯四步
① 状态
queen(r) 要放第 r 行；res 里是已放的 (x, y)，一行一个，所以不会同行。
② 选择与剪枝
用已放皇后算出 ban_c，枚举列 c。在集合里就跳过。
③ 递归
res.append((r, c)) 后调用 queen(r + 1)。
④ 撤销 / 收集
返回后 res.pop()。r >= n 时按坐标拼棋盘，resp.append(tmp) 再 return。
皇后 (x, y) 投影到第 r 行，禁止三列：同列 y、一条斜线 y + (r - x)、另一条 y - (r - x)。把它们放进 ban_c。集合里可能出现负数或 ≥ n 的值，对 for c in range(n) 没有影响。
示例： n=1（唯一解） n=4（2 个解） n=5（10 个解） n=6（4 个解） n=8（92 个解）
支持 n=1～8。n 越大搜索步骤越多；学习回溯建议先看 n=4。

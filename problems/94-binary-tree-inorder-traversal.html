94. 二叉树的中序遍历 · 递归动画

对每个节点严格执行 Left → Root → Right：先完整遍历左子树，再把当前值加入 resp，最后遍历右子树。
递归的三段式
① LEFT
调用 subTree(node.left)。必须等左子树全部返回，才能访问当前节点。
② ROOT
执行 resp.append(node.val)。这才叫“访问”当前节点。
③ RIGHT
调用 subTree(node.right)，完成后当前调用才可以返回。
中序遍历不是按节点值排序。它描述的是树的结构顺序 Left → Root → Right；只有对二叉搜索树中序遍历时，结果才恰好是非递减序列。
示例： 经典 [1,3,2] 完全二叉树 左斜树 右斜树 单节点 空树
接受空白分隔（1 null 2）或逗号分隔（[1,null,2]），可带一对方括号；null 与 # 表示空位置，且必须小写。 空输入、[]、单独的 null 或 # 表示空树。节点值须为 −1,000,000～1,000,000 的整数；拒绝空 token、混合分隔、未配对括号、根为空后仍有 token，以及没有可用父节点的孤儿 token。

复杂度
时间 O(n)每个实际节点恰好访问一次；null 基例不改变渐进复杂度。
空间 O(h)递归调用栈深度等于树高 h，不计返回数组所占空间。
最坏 O(n)，平衡树 O(log n)斜树的调用栈最深；高度平衡时树高为对数级。

437. 路径总和 III · 前缀和 + 回溯

路径可以从任意祖先的下一节点开始，但必须向下连续。DFS 用哈希表记录当前根路径上各前缀和的出现频次。
为什么查询 currentPrefix − target
① PREFIX
到当前节点累加 pre_sum += node.val，它是从根到当前节点的前缀和。
② NEED
由 currentPrefix - ancestorPrefix = target，所需祖先前缀为 currentPrefix - target。
③ COUNT
哈希表存的是频次；同一前缀可能在路径上出现多次，因此一次查询可能新增多条合法路径。
④ BACKTRACK
离开节点前执行 mapper[pre_sum] -= 1，只让当前递归路径的前缀参与查询。
公式：currentPrefix - ancestorPrefix = target，所以查询 need = currentPrefix - target。初始化 {0: 1} 表示根节点之前有一个前缀 0，因而能统计“恰好从根开始”的合法路径。
回溯不可省略：左子树返回后必须撤销它的前缀，否则右子树会错误读取一条并非其祖先链上的状态。pre_sum 是整数，递归参数按值传递，返回父层后自然恢复，无需再手动减去 node.val。
示例： 经典 → 3 负数 → 4 target=0 / 多路径 → 5 重复值多路径 → 6 单节点 → 1 空树 → 0
树接受空白分隔（1 null 2）或逗号分隔（[1,null,2]），可带一对方括号；null 与 # 必须小写。 空输入、[]、单独的 null 或 # 表示空树。支持负数、0、重复值和不完整树；节点值与 targetSum 须为 32 位有符号整数。严格拒绝非法/空 token、混合分隔、未配对括号、根为空后仍有 token，以及孤儿 token。

复杂度与字典空间的准确口径
平均时间 O(n)每个节点进入一次；前缀频次的哈希查询、加一与减一平均都是 O(1)。哈希表极端退化不计入通常分析。
递归栈 O(h)h 为树高。pre_sum 是整数值参数；当前路径和递归栈最多 h 层。
defaultdict 总键数最坏 O(n)用户版本查询缺失 need 会创建 0 键，回溯减一也不删除 0 键，所以历史键可能保留到 O(n)。若只看非零有效频次，则始终对应当前路径，最多 O(h)；可用 .get(need, 0) 并在计数归零时删除键来细化实际空间。

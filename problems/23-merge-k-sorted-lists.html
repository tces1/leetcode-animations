23. 合并 K 个升序链表 · 平衡两两归并

把 lists 当作待合并链表头的工作区：每轮用 read = 0, 2, 4... 读取，用 write = 0, 1, 2... 写回前缀，最后一次 del lists[write:] 压缩有效槽位。
自底向上归并的四个动作
① 成对读取
每轮固定当前有效槽位，从 read = 0 开始，每次读取相邻两条链并令 read += 2。
② 稳定 merge
dummy + tail 复用原节点；值相等时用 <= 先选左链，保持稳定。
③ 奇数项直接写
最后只剩一条链时，不参与 merge，直接执行 lists[write] = lists[read]。
④ 一次删除旧尾部
本轮写完后执行 del lists[write:]；有效链表数从 k 变成 ceil(k / 2)。
轮次平衡：有效链表数按 k → ceil(k/2) → ... → 1 下降；等价地，每条结果链覆盖的原链表数量约按 1 → 2 → 4 → 8 增长。
为什么是 O(N log k)：设所有链表共有 N 个节点。每轮所有节点合计只被 merge 一次，代价 O(N)；共有 O(log k) 轮，所以总时间 O(N log k)。朴素做法每取一个节点都扫描 k 个链表头，需 O(Nk)。实际算法只维护指针并原地复用输入数组，额外空间 O(1)。
示例： LeetCode 经典 奇数 5 条 含空链 全空 单链 重复值 · 稳定
严格支持 1～8 条链、总计最多 24 个节点、每条最多 10 个 −999～999 整数。链表之间只用 ;；节点只用空格或单个逗号分隔；空链必须明确写成 ∅。每条非空链必须非递减。

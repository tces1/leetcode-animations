215. 数组中的第 K 个最大元素 · 快速选择动画

全排序当然能做：排完取下标 n − k 就是第 K 大，但是 O(n log n)。本题只要这一个名次，所以金色钉钉的是排好后会坐在这里的位置，不是某个原始元素。三路划分后只走进含这个下标的一侧，左右内部不必再排，期望 O(n)。
快速选择四步
① 只要这个名次
全排序会把每个位置都排好。这里只关心升序下标 target = n − k：它一旦落进等于区，答案就是 pivot，左边更小、右边更大即可，不必继续排。
② 随机基准
在 [lo, hi] 里随机抽一个值，换到区间左端当 pivot。避免有序输入总选到最值，退化成 O(n²)。
③ 三路划分
lt / i / gt 三指针一次扫描：< pivot 换到左边，> pivot 换到右边，相等就让 i 右移。
④ 丢掉另一侧
target < lt 丢掉右边；target > gt 丢掉左边。被丢掉的那一段永远不会再排——这就是比全排序省的原因。
为什么不直接 sort？排序要确定全部名次，所以是 O(n log n)。快速选择每趟只递归含 target 的一侧，规模大约 n + n/2 + n/4 + … ≈ 2n，期望 O(n)。金色钉始终标着这个名次下标，方便对照「答案会坐在哪」；格子里的值会在交换中换进来。
为什么必须三路？若只按 < / ≥ 两路切，全相等数组几乎不缩小区间，LeetCode 会超时。三路把所有等于基准的元素一次归位，这种输入也是线性。
示例： 经典 k=2 大量重复 k=4 全相等 逆序 已有序 · 最大值 短数组 k=1
1～16 个整数，空格或逗号分隔，范围 −999～999。同一输入固定种子，路径可复现；「换一组随机基准」会换一条划分路径。

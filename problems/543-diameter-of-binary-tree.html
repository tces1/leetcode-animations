543. 二叉树的直径 · 后序 DFS

从叶到根，每个节点只计算一次：孩子返回深度，当前节点尝试用左右最长链拼出一条直径，再向父节点返回单边深度。
标准后序一次 DFS
① CHILD DEPTHS
left = depth(node.left)，right = depth(node.right)；null 深度为 0。
② UPDATE DIAMETER
经过当前节点的候选直径为 left + right，更新全局最大值。
③ RETURN DEPTH
向父节点只能延伸一侧，返回 1 + max(left, right)。
单位刻意不同：left/right 深度按节点数；直径按边数。左链有 left 个节点就含 left 条“从当前节点向下”的边，右侧同理，所以候选正好是 left + right，无需减一。
全局直径不一定经过根。每个节点都作为一次潜在最高拐点；全局变量保留所有候选中的最大值。
示例：经典 → 3直径不经过根 → 6斜树 → 3单节点 → 0空树 → 0
接受空白分隔或逗号分隔，可带一对方括号；null / # 必须小写。空输入、[]、单独的 null 或 # 表示空树。支持负数、重复值与不完整树；严格拒绝空 token、混合分隔、未配对括号、空根后的额外 token 与孤儿 token。

复杂度与单位
时间 O(n)每个节点在后序中恰好处理一次，每次只做常数次比较和加法。
递归栈 O(h)h 是树高；平衡树 O(log n)，斜树最坏 O(n)。

138. 随机链表的复制 · 原地穿插三趟动画

不用哈希表：先把每个副本紧邻放在原节点后，再借助这个位置关系复制 random，最后拆成两条独立链表并恢复原链表。
O(1) 额外空间的三个阶段
① weave · 穿插
copy = Node(curr.val, curr.next)，再令 curr.next = copy，逐节点形成 O0→C0→O1→C1…。
② random · 映射
copy.random = curr.random.next。原 random 目标的紧邻后继，正是该目标的副本。
③ detach · 拆分
同时恢复 curr.next，并让 copy.next 跳到下一个副本；最终两条链完全独立。
为什么是 curr.random.next？穿插完成后，每个原节点 Oj 的后继恒为自己的副本 Cj。若 Oi.random = Oj，则 Oi.random.next = Oj.next = Cj，无需额外的原→副本映射表。时间 O(n)，输出链表外额外空间 O(1)。
示例： LeetCode 经典 两节点互指 单节点自指 全部 null 重复值（看身份）
严格支持 1～8 个 −999～999 的整数节点；random 项数必须相同，每项只能是 −1 或 0～n−1。重复值不会合并，random 按节点身份连接。

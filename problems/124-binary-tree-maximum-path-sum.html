124. 二叉树中的最大路径和 · 后序 DFS

每个节点同时维护“能继续交给父节点的单边贡献”和“整棵树中已经见过的任意合法路径”。
标准后序 DFS：截断子树负贡献
① CLAMP CHILD GAINS
leftGain = max(dfs(left), 0)，右侧同理。子树返回负数时明确舍弃为 0，不让它拖低当前路径。
② THROUGH CURRENT
through = node.val + leftGain + rightGain。当前节点作为最高拐点，可连接左右两条正贡献链。
③ UPDATE & RETURN
resp = max(resp, through)；再返回 node.val + max(leftGain, rightGain)，给父节点时只能选择一边。
示例：经典 → 421 2 3 → 6全负 → -2一正一负 → 9单节点 → -7斜树 → 10

124. 二叉树中的最大路径和 · 后序 DFS

每个节点同时维护“能继续交给父节点的单边贡献”和“整棵树中已经见过的任意合法路径”。
标准后序 DFS：截断子树负贡献
① CLAMP CHILD GAINS
leftGain = max(dfs(left), 0)，右侧同理。子树返回负数时明确舍弃为 0，不让它拖低当前路径。
② THROUGH CURRENT
through = node.val + leftGain + rightGain。当前节点作为最高拐点，可连接左右两条正贡献链。
③ UPDATE & RETURN
resp = max(resp, through)；再返回 node.val + max(leftGain, rightGain)，给父节点时只能选择一边。
示例：经典 → 421 2 3 → 6全负 → -2一正一负 → 9单节点 → -7斜树 → 10
接受空白或逗号分隔，可带一对方括号；null / # 必须小写。支持负数、全负、重复值和不完整树；节点值须为 32 位有符号整数。严格拒绝空树、非法/空 token、混合分隔、未配对括号、空根和孤儿 token。

复杂度与全负边界
时间 O(n)每个节点访问一次，常数时间计算截断后的左右贡献、through、returnGain 与 resp。
递归栈 O(h)h 为树高；平衡树 O(log n)，斜树最坏 O(n)。
resp 必须从 −∞ 开始不能初始化为 0；全负树的左右贡献都会舍弃为 0，答案仍是最大单节点，如 [-3,-2,-5] → -2。

124. 二叉树中的最大路径和 · 算法动画

路径是树上任意一条首尾相连的节点序列，不必经过根。关键观察：任何一条路径，都恰好在最高的那个节点处拐一次弯（或者不拐弯）。于是枚举「拐点」就能不重不漏地枚举所有路径 —— 一趟后序遍历即可，O(n) 时间。
思路要点
① 路径只拐一次弯
把路径上深度最浅的节点叫拐点。以它为界，路径 = 左边一条下垂链 + 拐点 + 右边一条下垂链。每条路径的拐点唯一，所以枚举每个节点当拐点就枚举完了所有路径。
② 递归只返回单侧链
gain(node) 返回的是「从 node 出发一路向下能拿到的最大和」。必须单侧 —— 因为父节点还要接着往上走，路径在这里不能分叉。所以是 val + max(l, r)。
③ 负链直接丢弃
子树贡献为负就不如不要，用 max(gain(child), 0) 截断。图中这条边会变成灰色虚线，表示这条链没被采纳。
④ 答案在拐点处更新
在每个节点用 val + l + r（双侧）去刷新全局 ans。这一步是副作用，和返回值各管各的 —— 这就是本题最容易写错的地方。
⚠️ 返回值 ≠ 答案。val + l + r 只能写进全局变量，不能当作 gain 的返回值往上传；否则父节点接上来就得到一条分叉的「非路径」。动画里请注意对比每个节点的 ↓ 返回值 和 ⤳ 拐弯值。

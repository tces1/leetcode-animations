33. 搜索旋转排序数组 · 二分动画

数组原本升序，在某个下标处被旋转过一次，元素互不相同。任意切一刀，至少有一半是有序的：用 nums[l] <= nums[mid] 判断左半是否有序，再看 target 在不在这半里，丢掉另一半。闭区间 while l <= r，时间 O(log n)。
思路要点
① 状态
l, r = 0, n-1，mid = (l+r)//2。先看 nums[mid] == target，是就返回。
② 哪边有序
nums[l] <= nums[mid] → 左半 [l, mid] 有序；否则右半 [mid, r] 有序。
③ 落在有序半区？
左半有序时看 nums[l] <= target < nums[mid]；右半有序时看 nums[mid] < target <= nums[r]。
④ 收缩
在有序半区里就丢掉另一半；否则丢掉有序那半。直到 l > r，返回 -1。
不必先找旋转点。旋转点一定在无序那一半里。有序半区可以当普通二分用：target 的值域一目了然。注意左半判断是 target < nums[mid]（等于已经在上面返回了）。
示例： 找 0 → 4 找 3 → -1 5 1 3 找 3 3 1 找 1 无旋转 单元素未命中
需为「升序数组旋转一次」且元素互不相同；长度 1～14（动画清晰度上限）。

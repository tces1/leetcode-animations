48. 旋转图像 · 原地旋转动画

将 n×n 矩阵顺时针旋转 90°，要求原地完成（不能使用额外矩阵）。这里演示两种经典 O(n²) 时间、O(1) 空间的方法。
方法 A：转置 + 翻转每行
方法 B：四元素循环交换
思路要点 · 方法 A
① 观察规律
旋转后 new[j][n-1-i] = old[i][j]。把它拆成两步更容易实现。
② 转置
沿主对角线交换 mat[i][j] ↔ mat[j][i]（只处理 i<j 的上三角，避免重复交换）。
③ 翻转每行
对每一行做左右翻转（双指针对称交换），即可得到顺时针 90° 结果。
④ 复杂度
两步各 O(n²/2) 次交换，合计 O(n²)，额外空间 O(1)。
思路要点 · 方法 B
① 同心环
把矩阵看成若干同心方环，从外到内逐层处理，共 ⌊n/2⌋ 层。
② 四元素一组
每次取四个对称位置（上/右/下/左），一次旋转到位：top←left, right←top, bottom←right, left←bottom。
③ 每层 n-1-2·layer 组
每层沿边滑动 offset=0,1,… 依次处理，每组只用一个临时变量。
④ 复杂度
每个元素恰好参与一次四元素交换，时间 O(n²)，额外空间 O(1)。
怎么想到的：先只转四个角，再加偏移推广

第 1 步 · 只看四个角。最容易想清楚的是矩阵的四个角。以 n×n 为例，四个角坐标是 [0][0]（左上）、[0][n-1]（右上）、[n-1][n-1]（右下）、[n-1][0]（左下）。顺时针转 90° 后，左上跑到右上、右上跑到右下、右下跑到左下、左下跑到左上——正好是一个四元素的循环。

top = matrix[0][0] # 暂存左上 matrix[0][0] = matrix[n-1][0] # 左下 → 左上 matrix[n-1][0] = matrix[n-1][n-1] # 右下 → 左下 matrix[n-1][n-1] = matrix[0][n-1] # 右上 → 右下 matrix[0][n-1] = top # 左上 → 右上

用一个临时变量 top 存住起点，其余三个依次“搬家”，最后把暂存值放回空出的位置。这四个角就一次转到位了。

第 2 步 · 沿边滑动，加入 offset。四个角只是最外环上的一组。外环的边上还有其它元素：把上边从左往右数第 offset 个格子作为新的“上”，它对应的另外三个位置也跟着偏移。把上面写死的 0 / n-1 换成带 offset 的通式：

first, last = layer, n-1-layer top = matrix[first][first+offset] matrix[first][first+offset] = matrix[last-offset][first] # 左 → 上 matrix[last-offset][first] = matrix[last][last-offset] # 下 → 左 matrix[last][last-offset] = matrix[first+offset][last] # 右 → 下 matrix[first+offset][last] = top # 上 → 右

当 offset=0 时它就退化成第 1 步的四个角；让 offset 从 0 走到 last-first-1，就把这一整环都转完了。（代码里为了简洁，直接用循环变量 k=first+offset 代替，写成 matrix[first][k]、matrix[k][last]，与此处等价。）

第 3 步 · 一圈套一圈。外环转完，layer++ 缩进一圈，对里面的小环重复同样的事，直到 layer < n/2 结束。奇数阶最中心那一格是旋转中心，不动，自然被跳过。

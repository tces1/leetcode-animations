17. 电话号码的字母组合 · 回溯动画

每位数字对应按键上的若干字母。res 保存已经选好的前缀，sub_digits 是还没处理的后缀。取当前第一位，枚举它的每个字母：拼上 → 递归剩余后缀 → 去掉末尾字符。后缀为空时收集完整组合。
回溯流程
① 映射
lst[2..9] 对应 abc … wxyz；下标就是数字本身。
② 状态
res 是当前字符串，sub_digits 是剩余数字。
③ 选择 / 递归
取 sub_digits[0]，对每个字母 res += c，再 dfs(sub_digits[1:])。
④ 收集 / 撤销
剩余为空就收集；返回后 res = res[:-1]。
Python 字符串不可变：resp.append(res) 保存的是当前这个字符串对象，后面 res += c 会生成新串，不会改掉已经收集的结果。Java 若用 StringBuilder，收集时必须 toString()。
示例： 23279234
请输入 1～4 个数字，每位只能是 2～9，例如 23。本题按键不含 0 和 1。
输入 digits（黄=当前位，紫=已选完，蓝框=尚未处理）
电话按键 lst[2..9]
当前数字对应的字母 lst[n]
当前路径 res
调用栈（底 → 顶）
已经收集的组合（按 DFS 顺序）

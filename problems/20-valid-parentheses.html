20. 有效的括号 · 栈匹配动画

栈顶永远是「最近还没配上的左括号」。遇左括号就压栈；遇右括号必须和栈顶正好是一对，否则立即失败。扫完栈必须为空。
判定规则
① 左括号
( [ { 直接入栈，等待将来的右括号。
② 右括号
弹出栈顶，必须与 ) ] } 配成一对。
③ 栈空来右
没有左括号可配 → 非法。
④ 类型不对
例如栈顶是 ( 却来了 ] → 非法。
⑤ 扫完仍有剩余
栈里还剩左括号，说明没配完 → 非法。
为什么用栈：最近出现的左括号必须最先被匹配（后进先出）。嵌套 {[]} 合法，交叉 ([)] 不合法，差别就在栈顶对不对得上。
示例： () ()[]{} {[]} (] ([)] (( ()) {[()]}
( ↔ ) [ ↔ ] { ↔ }

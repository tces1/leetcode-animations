146. LRU 缓存 · 哈希表 + 双向链表动画

哈希表保存 key → Node，平均 O(1) 定位；双向链表从 HEAD 一侧的 MRU 排到 TAIL 一侧的 LRU。成功的 get 和 put 都会刷新“最近使用”。
每次操作最多四个阶段
① 查表
map.get(key) 平均 O(1) 找到节点身份；get miss 直接返回 −1，不改链表。
② 摘除
命中已有节点时令前后邻居互连：prev.next = next 与 next.prev = prev。
③ 插到头部
把节点放到 HEAD 后，成为 MRU。更新已有 key 只改 value，不增加 size。
④ 超容淘汰
新插入后若超容，淘汰 TAIL.prev，并同步从链表和 map 删除。
为什么需要 dummy HEAD / TAIL：头插、摘除和删尾都不必区分空表、首节点或尾节点。每次只改常数条引用，所以 get / put 平均时间 O(1)，空间 O(capacity)。
示例： 经典容量 2 更新已有 key 反复 get 容量 1 负 key / value
严格接受 1～24 个 get(key) 或 put(key,value)；操作名区分大小写，参数必须是 −1,000,000～1,000,000 的整数，操作之间必须用单个分号分隔。拒绝空操作、缺参、多参、小数和其它语法。

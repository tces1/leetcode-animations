19. 删除链表的倒数第 N 个结点 · 双指针动画

增加 dummy 统一处理删头；让 fast 先走 n+1 步，再与 slow 同步前进。fast 到达 null 时，slow 恰好停在待删节点的前驱。
为什么保持 n+1 的指针距离
① 增加哨兵
dummy.next = head，fast 与 slow 都从 dummy 出发，删头也有合法前驱。
② 拉开间距
fast 先走 n+1 步，使两个指针之间隔着 n 个真实节点。
③ 同步前进
之后 fast、slow 每轮各走一步，固定间距不会改变。
④ 重连删除
fast 到 null 时，执行 slow.next = slow.next.next，跨过目标节点。
边界统一：当删除头节点时 slow 留在 dummy；删除尾节点时 slow 停在倒数第二个节点；单节点链表删除后返回 dummy.next = null。时间 O(n)，额外空间 O(1)。
示例： 经典删除 4 删除头节点 删除尾节点 单节点 含负数 重复值
严格支持 1～12 个 −999～999 的整数；n 必须是整数且满足 1 ≤ n ≤ 链表长度。

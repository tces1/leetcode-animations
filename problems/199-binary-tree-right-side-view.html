199. 二叉树的右视图 · DFS / BFS 对照

从树的右侧向左看，每一层只能看到一个节点。默认突出右子树优先 DFS：某个 depth 第一次到达的节点就是该层右视节点。
示例： 经典 [1,3,4] 右子树浅 [1,3,5] 左斜树 右斜树 完全树 单节点 空树
接受空白分隔（1 null 2）或逗号分隔（[1,null,2]），可带一对方括号；null 与 # 表示空位置，且必须小写。 空输入、[]、单独的 null 或 # 表示空树。支持负数、重复值和不完整树；节点值须为 −1,000,000～1,000,000 的整数。严格拒绝非法或空 token、混合分隔、未配对括号、根为空后仍有 token，以及没有可用父节点的孤儿 token。

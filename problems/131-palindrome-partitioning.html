131. 分割回文串 · 回溯动画

把字符串 s 切成若干段，要求每一段都是回文串，返回所有切法。回溯用 start 表示剩余串的起点，枚举结束下标 end，用 check_string(start, end) 在原串上双指针判断。前缀是回文才切下去，start == n 时收集方案。视角 B 用一张完整的 isPal 表做 O(1) 查表。
回溯三要素
① 状态
用 start 表示「剩余待分割的子串从下标 start 开始」，已选的若干回文段记在 res 里，全部方案记在 resp。
② 选择
枚举 end（含），调用 check_string(start, end) 看 s[start..end] 是不是回文；是才切这一段。
③ 递归 / 回退
选了就 dfs(end + 1)；返回后 res.pop()，换更长的前缀。
④ 终止
start == n：剩余为空，resp.append(res.copy()) 收集后 return。
⑤ 剪枝
前缀不是回文就跳过。视角 B 预先填完整张 isPal 表，判断变成 O(1) 查表。

102. 二叉树的层序遍历 · 两种 layer 写法

同一棵树、同一份分层结果：DFS 实际按前序访问后按 layer 归档；BFS 用 deque((node, layer)) 严格按层访问。
示例： 经典 完全树 左斜树 右斜树 单节点 空树
接受空白分隔（1 null 2）或逗号分隔（[1,null,2]），可带一对方括号；null 与 # 表示空位置，且必须小写。 空输入、[]、单独的 null 或 # 表示空树。支持负数、重复值和不完整树；节点值须为 −1,000,000～1,000,000 的整数。严格拒绝非法 token、空 token、混合分隔、未配对括号、根为空后仍有 token，以及没有可用父节点的孤儿 token。

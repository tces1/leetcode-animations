114. 二叉树展开为链表 · O(1) 原地迭代

curr 沿 right 前进。若有左子树，就找到其最右节点 predecessor，把原右子树接到它后面，再把整棵左子树搬到右边并清空 left。
每次只重连引用，不交换节点值
① FIND
从 curr.left 出发，沿 right 找到最右节点。
② SAVE
记住 curr.right；动画单独显示这条原右子树入口。
③ ATTACH
predecessor.right = curr.right，把原右子树接到左子树尾部。
④ MOVE / CLEAR
curr.right = curr.left，随后 curr.left = None。
⑤ ADVANCE
curr = curr.right，继续处理前序中的下一个节点。
身份不变：所有节点 id 与 value 始终不变，只改写 left/right。最终所有 left 都为 None，从根沿 right 的顺序恰好是原树前序遍历。
示例：经典不完整树只有左边只有右边单节点空树
接受空白或逗号分隔，可带一对方括号；小写 null 或 # 表示空位。空输入、[]、单独 null 表示空树。严格拒绝空 token、混合分隔、非法整数、未配对括号、根为空后仍有 token 和孤儿 token；允许重复节点值。

复杂度与正确性
时间 O(n)外层沿最终 right 链访问每个节点；寻找最右节点时，每条相关 right 边总共只被常数次经过，总工作仍是 O(n)。
额外空间 O(1)算法只使用 curr、predecessor 等有限引用；页面为回放保存的快照不属于算法空间。
原地前序链不创建替代节点、不交换值；最终节点身份集合不变、无环、全 left 为空，right 链等于原树前序。

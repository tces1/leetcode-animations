234. 回文链表 · 原地反转动画

用 fast / slow 找到后半段起点，原地反转后以 p1 / p2 比较。全过程时间 O(n)，额外空间 O(1)。
三个阶段
① 定位后半段
slow 每次走一步，fast 每次走两步；循环条件为 fast && fast.next。
② 原地反转
从 slow 开始逐条改写 next，得到后半段的新头 secondHead。
③ 逐节点比较
p1 = head、p2 = secondHead 同步前进；遇到不相等立即返回 false，否则比较到 p2 = null 后返回 true。
为什么只比较后半段长度？反转后的 p2 恰好覆盖需要配对的后半段；偶数长度比较 n/2 对，奇数长度会额外让中间节点与自身比较一次，不影响结果。LeetCode 本题不要求保持输入链表结构，因此无需恢复；代价是算法结束后，后半段节点的 next 指针仍保持反转状态。
示例： 奇数回文 偶数回文 非回文 单节点 含负数 重复值
支持 1～10 个整数，节点值范围 −999～999；只接受空格或单个逗号分隔。连续逗号、小数和其它字符会被拒绝。

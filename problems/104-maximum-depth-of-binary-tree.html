104. 二叉树的最大深度 · 自顶向下 DFS

沿根到节点的路径携带 depth，访问节点时用 depth + 1 更新全局 maxDepth，再递归左右子树。
自顶向下的三步
① CALL
dfs(node, depth) 中，depth 表示当前节点之前已有多少个节点；根收到 depth = 0。
② UPDATE
当前节点按节点数计的深度是 depth + 1，执行 maxDepth = max(maxDepth, depth + 1)。
③ DESCEND
分别调用 dfs(node.left, depth + 1) 与 dfs(node.right, depth + 1)，null 由统一基例返回。
根节点深度按节点数为 1。用户代码从 dfs(root, 0) 开始，因此访问根时使用 0 + 1。无需先写 if node.left/right，因为 dfs(None, ...) 已由基例安全处理；变量建议拼写为 depth，不是 deepth。
另一种简洁视角（自底向上）：depth(node) = 1 + max(depth(left), depth(right))。它等待子树答案返回；本页动画主线仍是携带深度的自顶向下 DFS。
示例： 经典深度 3 右斜树 左斜树 完全树 单节点 空树
接受空白分隔（1 null 2）或逗号分隔（[1,null,2]），可带一对方括号；null 与 # 表示空位置，且必须小写。 空输入、[]、单独的 null 或 # 表示空树。支持负数与重复值；节点值须为 −1,000,000～1,000,000 的整数。严格拒绝空 token、混合分隔、未配对括号、根为空后仍有 token，以及没有可用父节点的孤儿 token。

复杂度
时间 O(n)每个实际节点恰好访问一次；对 null 的常数次调用不改变渐进复杂度。
空间 O(h)额外空间来自递归调用栈，h 是树高；当前路径只是调用栈的可视化。
平衡树 O(log n)，最坏 O(n)平衡树高度为对数级；左斜树或右斜树的调用栈会增长到 n 层。
